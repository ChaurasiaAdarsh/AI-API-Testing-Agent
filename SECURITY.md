# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability or SSRF bypass within this project:
1. Please do not open a public issue.
2. Draft an advisory or contact the repository maintainers directly with reproduction details.
3. Include relevant HTTP payloads, target endpoints, and configuration flags in your report.

All reports will be acknowledged and evaluated promptly.
